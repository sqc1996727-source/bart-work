# 巨龙物流工作台 · 界面设计规范

> 提炼自 unslop（Damir Sokolovsky，CC BY 4.0）的"反 AI 味"方法论，改写成巨龙内部规范。
> 给所有做前端的人（含子 agent）看：做界面之前先读这个，做完对着最后的检查清单自查。

## 一句话铁律

**AI 味 = 颜色和效果撒在框框、背景、按钮、标签上；真设计 = 框框保持安静，把功夫放进一两处让人记住的内容里。**

界面"丑到爆"的病根，就是违反了这个铁律：紫渐变、emoji 图标、发光边框、圆角卡片堆满、间距随机。

---

## 一、方向五行（动手前先写清这五行，没写清不许动代码）

1. **产品**：一句话说清给谁用、干什么。例：给物流公司老板/调度/员工的内部工作台，查运单、对账、催回单。
2. **性格**：2-3 个具体词。**禁用** clean / modern / minimal / premium 这种"所有模板都成立"的空话。
3. **世界**：这产品天然属于什么材质/场景（决定中性色往哪偏）。物流 = 运单、路线、货站、票据 → 纸感、墨色、暖。
4. **高光时刻**：1-2 处可以浓墨重彩的地方（不是满屏都亮）。
5. **签名细节**：一个只有巨龙才有的小特征，全站只用一次（例如：一条"路线线"）。

**巨龙的方向（已定）**：性格 = 沉稳、精确、有分寸；世界 = 货运纸面（暖中性色）；签名 = 路线线；高光 = "今日该盯的事"的数字 + 一张画得好的图。

## 二、九道工法（顺序有因果，必须按这个顺序，不能跳）

### 1. 间距（先做，节奏对了其他才好判）
- 一切落在 4px 栅格：4/8/12/16/20/24/32/40/48/64/80/96/128。
- **同类同尺寸**：列表所有行同高同距，一排卡片同 padding。
- 组内间距 < 组间间距。
- 删除 `mt-[13px]`、`py-[11px]` 这种破坏节奏的一次性碎值。
- 行高 32 紧凑 / 36 默认；卡片 padding 20-24；页面边缘 24-32。

### 2. 颜色
- 一条**带色调的中性灰阶**，背景/卡片/边框/文字全从这条来。暖色（纸感）适合物流。
- 文字只三层：primary / secondary / muted，不要十几种淡紫。
- 全屏**一个强调色**，用得极少：只标主要按钮、选中态、那一个关键数字。物流用琥珀/煤橙。
- **禁用**：紫到蓝渐变、渐变文字、彩色光晕、彩色阴影、霓虹边框、背景彩色光斑。
- 边框 = 文字色 6-10% 透明度的细线。
- 深色主题靠"表面层级 + 细线"做深度，**不靠阴影**。

### 3. 图标
- 所有 emoji 当图标/装饰的，全换成线性图标（lucide），16/18px、1.5 描边。
- 图标取 muted/secondary 文字色，**绝不自己上色**。
- 图标盒子每行同宽，跟标签间距固定 8-10px。
- 没意义的图标直接删（比如每个卡片标题前的 emoji）。

### 4. 文案
- 标题说清"这产品为谁干什么"，用页面已有事实，不编。
- **禁感叹号**、禁 `Welcome back, XX 👋` 式问候标题（标题写页面名/周期，如"11月24日"）。
- 短标签：`搜索` 不是 `搜索任何内容…`。
- 变化要写清跟谁比：`+12% 比上月`，不是 `+12%`。
- 标题/标签/按钮结尾**不加句号**。
- 禁 hype 词：supercharge / seamless / 解锁 / 颠覆 / AI赋能。
- 禁无法核实的吹牛：`服务 1 万+ 团队`、`快 10 倍`。
- 假数据要像真的，禁 `[X]`、`123,456`。
- 禁 `PRO`、`New ✨`、`Beta 🚀` 徽章。

### 5. 字体
- 一套字 + 最多一个搭档（等宽字体给数字/元信息）。
- 只几个字号 + 两个字重（400/500，最多 600）。**禁 700-900 大粗标题**。
- 层级靠"字号 + 颜色"，不靠字重。
- 一律句首大写（Sentence case），禁 `NAVIGATION` 式全大写宽字距。
- 数字用 `tabular-nums`，全屏一种格式。

### 6. 布局
- **保留板块和顺序**，不重排。
- 后台 App 保持真实比例：侧栏 240-280，内容区 fluid 封顶 1440-1600。
- 首屏作为整体构图，**不许有死空带**。
- 长标题左对齐；居中对齐只用于一两行短标题。
- 一个主行动 + 最多一个次行动。

### 7. 细节
- 嵌套圆角：内圆角 = 外圆角 − padding，不低于 4。控件 8-10、卡片 12-16、面板 14-20。
- 计数/元信息做成安静的文字（常等宽、muted），不做发光药丸。
- 图表：一个主图最大，其他数据用列表/表格，别放两个同样大的图。
- 统计卡只放数字（标签+大数字+变化），**不放迷你折线/图标填白**。
- hover/focus 状态要有，focus 环给键盘用户可见。

### 8. 视觉
- 删装饰性填充：玻璃球、光晕、星云、漂浮立方体、发光网格。
- **后台界面几乎不需要生成图片**。高光时刻来自产品本身：画得好的图、排得漂亮的数字、真实内容。
- 要生成图片只用于空状态/引导/营销时刻。

### 9. 动效（最后做）
- 删无意义循环动效：`animate-pulse`、`animate-ping`、标题 shimmer、呼吸光晕。
- 删 `transition-all`、弹跳弹簧、`hover:scale` 卡片。
- 只动 color/background/border/opacity/transform，且写明确（`transition-colors` 不是 `transition-all`）。
- 全站**一条缓动曲线**：`cubic-bezier(0.22, 1, 0.36, 1)`；时长 hover 120-180ms、入场 300-500ms。
- 入场最多一处，短淡入+微上移，别每张卡从不同方向飞进来。

## 三、精确值（可直接抄）

### 深色中性灰阶（Warm 暖，适合物流纸感）
| 角色 | 色值 |
|------|------|
| 最深层（侧栏） | #12110f |
| 页面背景 | #161513 |
| 卡片 | #1c1a18 |
| 浮起（选中行/输入框） | #262421 |
| 主文字 | #efe9de |
| 次要文字 | #aaa398 |
| 弱文字/图标 | #8a847a |
| 细线 | 主文字 8% 透明 |

### 强调色
琥珀/煤橙（物流暖世界）。文字压在强调色上要 ≥ 4.5:1 对比。全屏只占几个百分点。

### 语义色（收敛到调色板内）
- 正向（涨/好）：深色 #4cc38a，浅色 #16a34a
- 负向（跌/错）：深色 #e5484d，浅色 #dc2626

### 间距尺度
4/8/12/16/20/24/32/40/48/64/80/96/128

### 字号尺度
| 用途 | 字号 | 行高 | 字重 |
|------|------|------|------|
| 小标签/元信息/计数 | 12 | 16 | 400 |
| 次要文字/说明 | 13-14 | 20 | 400 |
| 正文/导航 | 14-15 | 20-22 | 400-500 |
| 卡片数字 | 28-32 | 1 | 500 tabular |
| 页面标题 | 28-36 | 1.15 | 400-500 |

### 圆角
键帽/标签/小按钮 4-6；行/输入/按钮 8-10；卡片 12-16；面板 14-20。

### 按钮
hero 44-48 高，导航 32-36；深色主按钮用灰阶 off-white 配深字，或强调色。

## 五、质感方向：液态玻璃 / 液态金属（2026-11-24 老大定）

> 上一版走 unslop 的"零阴影极端扁平"被老大否了（"太扁平化"）。老大定：**液态玻璃 / 液态金属质感**（Apple Liquid Glass 那种通透折射、镜面高光、弹簧手感）。下面是从 claude-artisan 的 liquid-glass 旗舰规格提炼的可落地 token。

### 核心设计 token（可直接抄）
```css
:root {
  --color-bg: #000000;                          /* 纯黑底，液态玻璃最出效果 */
  --color-surface: rgba(255,255,255,0.06);      /* 半透明玻璃表面 */
  --color-surface-strong: rgba(255,255,255,0.14);
  --color-border: rgba(255,255,255,0.30);       /* 玻璃描边 */
  --color-specular: rgba(255,255,255,0.65);     /* 镜面高光 */
  --color-text: #ffffff;
  --color-text-muted: rgba(235,235,245,0.60);
  --color-primary: #0a84ff;                     /* iOS 蓝 */
  --color-accent: #64d2ff;                      /* 天蓝强调 */
  --color-scrim: rgba(0,0,0,0.35);
  --radius-sm: 12px; --radius-md: 20px; --radius-lg: 28px; --radius-pill: 999px;
  --shadow-sm: 0 2px 10px rgba(0,0,0,0.25);
  --shadow-md: 0 10px 40px rgba(0,0,0,0.35);
  --shadow-lg: 0 20px 60px rgba(0,0,0,0.45);
  --shadow-edge: inset 0 1px 0 rgba(255,255,255,0.55), inset 0 -1px 0 rgba(255,255,255,0.10);
  --blur-backdrop: 20px; --blur-backdrop-thick: 40px;
  --ease-spring: cubic-bezier(0.2, 0.9, 0.1, 1.1);   /* 液态弹簧手感 */
  --ease-entrance: cubic-bezier(0.16, 1, 0.3, 1);
  --lens-highlight: linear-gradient(135deg, rgba(255,255,255,0.55) 0%, rgba(255,255,255,0.05) 40%, rgba(255,255,255,0) 70%);
  --refraction: saturate(1.8) brightness(1.1);        /* 透镜折射 */
}
```

### 液态玻璃的关键三招（"液态"和"玻璃"的区别就在这）
1. **镜面高光** `--shadow-edge`：玻璃顶部一条 1px 亮边（inset 0 1px 0 白 55%）+ 底部一条暗边。这是"液态"的灵魂，普通毛玻璃没有这条。
2. **折射** `--refraction: saturate(1.8) brightness(1.1)`：让玻璃背后的内容更饱和更亮，像被透镜折射。
3. **弹簧缓动** `--ease-spring`：hover/按下用弹簧曲线，有"液态弹性"。

### 10 类组件的液态表达
| 组件 | 液态表达 |
|------|---------|
| 按钮 | 胶囊 + 镜面边高光 + 按下弹簧缩放 |
| 输入框 | 凹陷玻璃，focus 加深折射、抬高镜面边（不是硬 focus 环） |
| 卡片 | 浮起玻璃 blur(20px) + 镜面边 + 同心圆角 |
| 导航 | 浮起工具栏，像"透镜"压在滚动内容上 |
| 弹窗 | 厚玻璃 blur(40px) 弹簧升起 + scrim 压暗背景 |
| 表格 | 内容留不透明面，只有工具栏/表头是液态玻璃 |
| tooltip | 小胶囊带镜面边 |
| 徽章 | 玻璃胶囊，靠深度/高光分层，不用饱和色 |
| 开关 | 玻璃轨道 + 实心旋钮弹簧滑动 |
| 加载 | 玻璃 shimmer + 镜面边扫光 |

### 无障碍（必须做，不能因为液态就丢）
- 尊重系统开关：Reduced Transparency（更实更磨砂）、Reduced Motion（去掉弹簧）、Increased Contrast（黑白+强描边）。
- 深度分层对低视力不可见 → 必须配真实对比度，不能只靠折射。
- Web 上是近似，要有不透明高对比 fallback。

### 与 unslop 的关系（别打架）
- unslop 的"去 AI 味"仍然成立：**液态玻璃 ≠ 紫渐变、发光边框、彩色光斑**。液态玻璃是"通透折射 + 镜面高光"，不是"紫到蓝渐变 + 霓虹光晕"。
- 关键区别：unslop 禁的是**彩色渐变和光晕**，液态玻璃用的是**白色镜面高光 + 中性折射**，一个色相都没有。所以两者不冲突——液态玻璃是"有质感的克制"，不是"回到 AI 味"。
