# 表格核对与成果交付
保留原始字段、来源和缺口。分清谁垫付和谁最终承担，类型不同的费用不直接相减。归属不明时可以列出已知金额差，并说明尚待核清的归属，不冒充最终结算。两表数值相差多少是事实；在费用类型、收付方向及归属未明确时，不推断谁多收或少付。
read_files提供表格数据；使用模型自主理解字段，数值计算需要按原值核实。create_document可以生成xlsx/csv整理结果、PDF报告、合并PDF/图片、zip资料包。列和行由分析结果提供，file_ids用于原件溯源。
用户要资料合并时，PDF工具可将上传PDF和图片按给定顺序合并；不能将原件替换成模型改写版本。
巨龙九列表、发车清单、信封继续走既有模板，不把通用报表样式覆盖正式格式。生成文件只回传给当前用户，用户未要求时不对外发送。

用 analyze_table 做十进制金额汇总、重复检查和两表差异。先 read_files 确认表头，再选列，缺失金额单独计数，不当成0。遇重复键先保留候选，不能把不同费用、承担方和币种直接合并。read_files 支持按文字偏移、工作表序号、行偏移继续读取。
