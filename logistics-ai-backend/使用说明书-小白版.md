# 巨龙物流 AI 助理 · 小白使用说明书

> 给第一次打开的人看。不用懂电脑、不用懂 AI，照着做就行。
> 一句话：**它是个会干活的同事，你跟它说话，它帮你查账、盯事、催单。**

---

## 一、它是谁，能帮我干什么

它不是你手机里那种"问一句答一句"的机器人。它是**住在你们公司系统里的一个员工**，认得你们的每一票货、每一笔钱、每一张回单。

它能帮你：

| 你想做的事 | 你直接说 |
|-----------|---------|
| 查一票货 | "0001348 那票到哪了？" |
| 看今天该盯什么 | "今天有什么要处理的？" |
| 对账、找差异 | "帮我对一下 11 月的账，有没有对不上的？" |
| 催回单 | "哪些回单还没收回来？" |
| 导文件 | "把 11 月奉贤的对账单导出来" |
| 让它每天自动干 | "以后每天早上 8 点帮我扫一遍账" |
| 转告同事 | "把这条催办发给调度小张" |

**核心就一句：当它是个靠谱同事，用大白话交代就行，不用记任何命令。**

---

## 二、第一次打开怎么用

1. 打开网址，输入你的账号密码登录。
2. 登录后，屏幕中间会有一个输入框，下面有几个按钮（比如"今天有什么事""帮我核对费用"）。
3. **在输入框里打字，回车发送**，它就开始干活了。

> 不确定问什么？直接点下面那几个现成的按钮，或者就一句"今天有什么要处理的？"

---

## 三、几个最常用的场景，照着做

### 场景 1：每天一上来，让它汇报今天的事

```
你：今天有什么要处理的？
```

它会自动扫一遍账，告诉你：
- 有哪几笔钱对不上（要你确认）
- 有哪几张回单该收还没收（要催）

**你只需要看它报出来的，一件件回它就行。**

### 场景 2：对一笔账，确认有没有问题

```
你：0001348 这票的 200 元差异怎么回事？
```

它会去查，告诉你这 200 元是怎么来的、问题在哪。如果确实有问题，你说：

```
你：这笔标成有差异
```

它就会记下来，留下"是谁、什么时候"确认的记录。

### 场景 3：让它每天自己跑（定时任务）

```
你：以后每天早上 8 点帮我扫一遍账，有差异推给我
```

它会设一个定时任务，以后每天早上 8 点**自己跑**，扫完把结果推给你，不用你记着去问。

> 想看/改/停这些定时任务：点界面右上角的 **"定时任务"** 按钮，里面能看到你设了哪些，能暂停、恢复、取消。

### 场景 4：催回单

```
你：哪些纸质回单还没回来？
```

它列出还没收回来的票，你可以让它"把这条发给调度去催"。

## 四、它有三种"身份"（不同岗位，看到的不一样）

系统里，不同岗位登录，是三个不同的"同事"：

| 你是谁 | 它像谁 | 能看到什么 |
|--------|-------|-----------|
| 老板 | 私人幕僚 | 全部，包括成本和利润 |
| 调度/管理 | 执行助理 | 单票和线路的收入成本，看不到全公司利润 |
| 员工 | 靠谱同事 | 自己的票和活，**看不到价格** |

**价格保密是铁规矩**：厂家的运费、底价，只在内部对账里出现。运单、打印件、发车清单、搜索，都不会露出来。

---

## 五、它靠谱在哪（你可以放心）

- **不乱改账**：钱的事，它只出"建议"，最后要你点头才落账，而且留痕（谁、什么时候、改了什么，都查得到）。
- **查不到就说查不到**：它不会编。系统里没有的，它会老实说"没查到"，让你再给个单号或日期。
- **你纠正过的，它记住**：比如你说"沈阳天运，以后简称天运"，它下次你说"天运"它就懂。

---

## 六、碰到问题怎么办

- **它答非所问？** 换个说法，把单号、日期、金额这些具体信息给全。
- **它说"没查到"？** 检查一下单号对不对，或者给它个日期范围。
- **它没反应 / 报错？** 刷新一下页面，重新登录试试。还不行就找管理员。

---

## 七、一句话总结

**别把它当"软件"，把它当"人"。** 你要查货、对账、催单、盯着每天的事——直接跟它说，它去干，干完告诉你结果。

有什么不会的，就先问一句："这个该怎么问你？" 它会教你怎么用它。
